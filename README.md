# グラスつみき — Glass Tsumiki

Meta Ray-Ban Display 用の**タイミング積み上げゲーム**。左右に往復するブロックを**タップで落として**下の段に重ねていく。はみ出した部分は**切り落とされて回転しながら落下**し、ブロックはだんだん細くなる。ぴったり重ねれば **PERFECT** で幅が少し戻り、連続するとコンボ。段が高くなるとカメラが上へスクロールし、色は段ごとにグラデーションで移り変わる。重ならなかったらおしまい — 積み上げたタワー全体を引きで見せる。アイソメ風の擬似3D、背景は透明。依存ライブラリなし・オフライン動作。

- **ライブURL**: https://glass-tsumiki.vercel.app
- **画面**: 600×600 / 加算式ディスプレイ対応（背景 #000000 = 透明）
- **依存ライブラリなし**（Vanilla JS / Canvas / 静的サイト）

## 特徴

- **タップ1つで遊べる** — ブロックは x 方向・z 方向を交互に往復。タップで落とすだけ
- **切り落とし** — 重なっていない部分は物理っぽく回転しながら落ちていき、次のブロックはその幅になる
- **PERFECT とコンボ** — ずれがごくわずかなら PERFECT。白いリングが広がり、幅が少し戻る。連続するほど戻る量が増える
- **だんだん速く** — 段数に応じて往復スピードが上がる
- **色のグラデーション** — 段ごとに色相がずれていき、加算式ディスプレイで映える高彩度のタワーになる
- **ゲームオーバーの全景** — カメラが引いてタワー全体を映し、光が下から上へ走る。段数・PERFECT回数・最大コンボを表示
- **ベスト段数** を保存

## 操作方法

| 画面 | 操作 |
|------|------|
| タイトル | ↑↓でえらんでタップ（「▶ スタート」「つかいかた」） |
| ゲーム | タップでブロックを落とす、← ↑ ↓ のどれかで一時停止メニュー |
| 一時停止メニュー | ↑↓でえらんでタップ（「← もどる」「やりなおす」「つかいかた」「タイトルへ」） |
| 結果 | ←→（↑↓）でえらんでタップ（「▶ もう一度」「タイトルへ」） |
| つかいかた | タップで「← もどる」 |
| PC確認用 | Escape でひとつ前の画面へ、キャンバスのクリックでも落とせる（グラスの戻るジェスチャーは使用不可のため補助のみ） |

`?auto=1` を付けると自動プレイ（録画用。ほぼ PERFECT を連発しつつ時々ずらして切り落としを見せ、17段目でわざと失敗してタワー全景を見せる。記録は保存しない）。`?miss=N` で失敗する段を変えられます。

## グラスへの登録

`qr-publish.png` の QR コードをスマホでスキャンすると Meta AI アプリが開き、自動で Web アプリとして登録されます。

ディープリンク:
```
fb-viewapp://web_app_deep_link?appName=%E3%82%B0%E3%83%A9%E3%82%B9%E3%81%A4%E3%81%BF%E3%81%8D&appUrl=https%3A%2F%2Fglass-tsumiki.vercel.app
```

手動登録の場合: Meta AI アプリ → デバイス → ディスプレイグラス設定 → アプリ接続 → Web アプリ → 「Web アプリを追加」で名前 `グラスつみき`、URL `https://glass-tsumiki.vercel.app` を入力。
